# 3. Software and cost

The method is implemented in `gwsource`. It is an open-source Python package (MIT licence). It reads the binary grid file and the budget file of a MODFLOW 6 Groundwater Flow (GWF) model, on any grid type. <!-- evidence: src/gwsource/mf6io.py module docstring (grb and cbc) --> Stream reaches, lakes and multi-aquifer wells can be traced as extra cells from their own budget files. GWF models joined by exchanges are read as one system. <!-- evidence: src/gwsource/network.py open_simulation (package_nodes need BUDGET FILEOUT, MVR too) --> Destinations and sources are chosen by package, boundname, cells or zone. <!-- evidence: src/gwsource/selectors.py (select: package, bounds, boundnames, cells, term, model; select_zone) --> Outputs export to netCDF and GeoPackage files. The code can also run MODFLOW 6 PRT on the same flows. <!-- evidence: src/gwsource/export.py (to_netcdf, to_geopackage); src/gwsource/prt.py (release_points, write_prt) --> The inputs, selections and outputs are listed in {SI: inputs, selections and outputs}.
