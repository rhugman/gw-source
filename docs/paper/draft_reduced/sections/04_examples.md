# 3. Worked examples

This section shows how a practitioner can use the code to answer three common questions and how far each answer can be trusted. The three worked examples ask where a well's water comes from (example A), how much of it is already in the aquifer (example B), and how much comes from each source and how old it is (example C). A paragraph before Table 1 then compares the outputs with other common approaches, such as particle tracking, transport with tagged water and a published study. The example sink is a well, but each output applies in the same way to a stream reach, a drain, a lake or a group of them. Fig. 2 shows one output of each type. A snapshot treats the flows of each step as steady, so it says which sources feed the well but not when their water entered the aquifer.
