# 9. Code and Data Availability

The code, `gwsource`, with its tests, tutorials and study scripts, is open source under the MIT licence at https://github.com/rhugman/gw-source [check: public URL]; a release with the CSV files behind every table and figure will be archived on Zenodo [check: DOI].
